MYSTERY SCOOP v1.0 — PLAYABLE WEB PROTOTYPE

Core loop:
Customer Order -> Scoop ALL requested scoops -> Sort ALL beads -> Reveal -> Choose product -> Pack -> Customer reaction -> Coins/XP.

Starter beads:
Common: Green Round = Pen; Yellow Star = Scrunchie; Red Heart = Notebook/Sticky Notes; Purple Flower = Sticker Pack.
Uncommon: Blue Butterfly = Keychain.
Rare: Blue/White Diamond = Squishie.
Epic: Pink Glitter Bow = Extra Scoop.
Legendary: Shiny Crown = Dealer's Choice.

No timers, ads or real-money purchases in this prototype.
